# Непрозрачный фон — исправление поверх audit.4

- Основной градиент панели: FA/F5 → FF/FF. Ползунок 255 теперь не оставляет внутренней прозрачности заливки. RGB, геометрия, углы и свечение сохранены.

# Изменения audit.4 — исправление SafeInt по журналу

- Переписана SafeInt: явные блоки условий и безусловный числовой return после ограничения диапазона.
- Развёрнуты 13 опасных однострочных числовых if-присваиваний, в том числе в загрузке строк профиля, задержек и категорий.
- Добавлена автоматическая числовая самопроверка из 14 случаев до загрузки профиля. При провале — остановка, а не работа с пустыми значениями.
- Добавлена диагностика входного и преобразованного значения непрозрачности.
- Исправление соответствует файлу из журнала: прежний размер 197187 байт, прежняя строка 1321 — сравнение результата SafeInt.

# Изменения audit.3 — непрозрачность

- Ползунок отправляет временную непрозрачность в AHK без записи INI.
- Изменения объединяются коротким таймером без откладывания до полного окончания движения ползунка.
- Непрозрачность включена в кэш кадра: изменение только alpha теперь вызывает перерисовку.
- Renderer берёт SourceConstantAlpha из того же кадра, который проверяется кэшем.
- Успешное сохранение снимает предпросмотр и использует записанное значение. Закрытие настроек отменяет несохранённый alpha и снимает отложенный таймер.
- Сброс настроек отправляет предпросмотр 235.
- Добавлены тесты крайних значений 80/255, значения 160, отправки сохранения и отмены предпросмотра.

# Изменения audit.2

- Добавлена проверка источника WebMessage: принимаются команды только от локальной страницы интерфейса.
- Добавлены запрет посторонней навигации внутри WebView2 и обработка новых окон: HTTP(S)-ссылки пользователя открываются отдельно, интерфейс остаётся на месте.
- Регистрация событий приведена к фактическому API вложенной WebView2.ahk; ошибка подключения теперь видна, а не скрывается цепочкой try.
- Локальный URI создаётся через UrlCreateFromPathW вместо ручной сборки строки.
- Усилена проверка HTTP(S)-URL перед передачей в Run.
- Исправлен протокол полей: текст с буквальным `|~|` больше не разделяется на лишние поля. Префикс `~ub2~` и буквальные percent-последовательности экранируются обратимо. Обычные сообщения сохраняют прежний формат.
- Минимальная ширина оверлея при сохранении согласована с загрузкой и импортом: 260 px.
- Добавлены регрессионные браузерные проверки разделителя и внешних ссылок, инструкции компиляции и этапов выпуска.
- Новые нативные вызовы и обработчики требуют проверки на Windows: в этой среде они не запускались.

- Удалены неиспользуемые библиотеки вне цепочки #Include, старые журналы, тестовые HTML и противоречащие друг другу старые инструкции.
