# UniBind 2027.10 Beta 1 — Hotfix 2

**Чистый комплект исходников для Windows-тестирования. Это не проверенный стабильный Windows-релиз. EXE в этом ZIP нет.**

Начните с `START_HERE_RU.md`: там порядок проверок, сборки и подготовки публикации. В этой поставке нет ваших рабочих config, backups и logs; храните свою рабочую папку отдельно.

UniBind — локальный биндер на AutoHotkey v2 с редактором сообщений, профилями, переменными и нативным оверлеем для GTA SA:MP RP. Не является официальным продуктом GTA, SA:MP, Microsoft или какой-либо игровой площадки.

## Hotfix 2
Исправлена сообщённая пользователем ошибка `Missing quote` в тестовой строке RunDataSelfTests: кавычки и точка с запятой формируются через Chr. Для установки достаточно заменить UniBind.ahk при закрытом приложении. Ниже также сохранено исправление Hotfix 1.

## Hotfix 1
Исправлена сообщённая пользователем ошибка AHK `Unexpected Else`: ветки if/else if в OnWebMessage заключены в явные блоки. В установленной Beta 1 достаточно заменить UniBind.ahk при закрытой программе; config/backups не удаляйте. Исправление всё ещё требует нативной проверки Windows.

## Что исправлено
- Единые ограничения: 100 строк на бинд, 4096 символов на строку, задержка 0…120000 мс. Превышение отклоняется, а не молча обрезается.
- Проверка целевого окна и отмены перед действиями ввода и после ожиданий; повторная отправка заблокирована до завершения очистки предыдущей.
- Клавиатура не блокируется на время сообщения, чтобы оставались доступны Стоп и Alt+Tab. Не печатайте параллельно с макросом.
- Сбой буфера обмена прерывает выполнение без сообщения об успешной отправке.
- Изменённые бинды/настройки сначала записываются, затем применяются к памяти. Категории и порядок сохраняются одним снимком профиля.
- Экспорт проверяется на возможность обратного импорта. Импорт применяет один прочитанный снимок и создаёт резервную копию для отката.
- Диалоги профилей, категорий и переменных закрываются по подтверждению сохранения.
- Рабочие config/backups/logs удалены. Шаблон медицинского профиля сохранён отдельно в lib/templates.

## Требования
- Windows 10/11; интерфейс требует окно не меньше примерно 1024×700. Нужна отдельная проверка DPI и нескольких мониторов.
- Для исходников: AutoHotkey v2, не v1. В журнале последнего пользовательского архива есть успешные запуски с AHK 2.0.29 и переключение профилей. Отдельные нативные самотесты, EXE и игровые сценарии ещё не подтверждены.
- Microsoft Edge WebView2 Runtime Evergreen. Вложенные WebView2Loader.dll не заменяют Runtime.
- Папка с доступом на запись, например C:\UniBind. Не запускайте из архива или Program Files.
- GTA SA/SA:MP — для игровых сценариев. Разрешённость макросов зависит от правил конкретного сервера.

## Установка исходников
1. Распакуйте ZIP целиком. Установите AutoHotkey v2 и WebView2 Runtime из официальных источников, если они отсутствуют.
2. Запустите **UniBind.ahk**; отдельные библиотеки запускать не нужно.
3. Выберите стартовый набор при первом запуске. Папки config, backups и logs создаются автоматически.
4. Проверьте свои данные и сочетания клавиш. Сначала тестируйте на отдельной копии и без важных открытых документов.
5. Пройдите RELEASE_CHECKLIST.md. Не объявляйте стабильный релиз до Windows-испытаний.

Для обновления: закройте приложение, сохраните всю старую папку отдельно; замените исходник, ui и lib. Свои config и backups не удаляйте. Строгая новая проверка может потребовать исправить старые данные, выходящие за лимиты.

## Использование и данные
- По умолчанию: оверлей F10, Стоп Backspace, ввод ID — P, полный/мини — M. Их можно переназначить.
- В режиме «только GTA» выполняется ввод в выбранное окно GTA. Без этого режима фиксируется активное целевое окно: потеря фокуса прерывает последовательность.
- Задержка 0 у строки означает использовать общую задержку между сообщениями; общая задержка 0 — без этой паузы.
- Пустые строки запрещены: заполните или удалите их. Управляющие символы и переносы строк внутри полей запрещены.
- Поддерживаются до 50 профилей, 50 категорий и 200 пользовательских переменных.
- Экспорт сохраняйте вне папки приложения, чтобы не перезаписать исходники/настройки. Предельный размер импортируемого/проверяемого экспорта — 50 МиБ.
- Перед импортом создаётся config/_import_sandbox_*. При ошибке снимок сохраняется; старые снимки могут удаляться после 7 дней. Важные копии храните вне папки приложения.
- Не включайте config, backups, logs, sandbox, кэш WebView2 и локальные результаты тестов в публичный архив.
