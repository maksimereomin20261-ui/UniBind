# Разработческие браузерные тесты

Требуются Node.js, Playwright и Chromium. Используется только локальный ui/ui.html, WebView2-мост имитируется, HTTP(S)-запросы блокируются. AHK не запускается.

Запуск из папки проекта: node tests/browser-smoke.cjs и node tests/regression-ui.cjs. Для своего Chromium задайте переменную окружения CHROMIUM_PATH. Скрипты сохраняют JSON рядом с собой и возвращают ненулевой код при сбое.

Нативные тесты — tools/Test-Windows.ps1. JavaScript-тесты не подтверждают разбор AHK и работу Win32. Сгенерированные локальные результаты не переносите в пользовательский релиз.
